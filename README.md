Per Lap is an arduino Project for a lap counter with many sensors.
I use it with 12 Mats car track and a 1/43 RC car
The original plan includes
- Camera for color recognition
- Secondary Module for color recognition
- Laser module for lap time (laser and photo sensor over the finish line)
- Secondary Magnetic Module for lap time

What currently works:
- Camera for color recognition
- Laser module for lap time

I use colored tape over the cars so the color recognition differentiates the well enough, sometimes indirect lamp lighting over the finish line helps if the webcam is old like the one I'm using.
